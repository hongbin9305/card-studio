# FRAME LAB — Card Studio

이미지와 문구를 조합해 SNS 카드 이미지를 제작하는 웹 기반 이미지 편집기입니다.

별도의 프로그램 설치 없이 브라우저에서 이미지와 텍스트를 편집하고, 완성한 카드를 PNG 또는 JPEG 파일로 저장할 수 있습니다.

## 배포 사이트

https://hongbin9305.github.io/card-studio/

## 주요 기능

- **이미지 업로드:** PNG 및 JPEG 이미지 업로드
- **텍스트 편집:** 문구 입력, 글자 크기 및 색상 변경
- **위치 조절:** X/Y 슬라이더를 이용한 텍스트 위치 조절
- **비율 변경:** 1:1, 4:5, 9:16 카드 비율 지원
- **실시간 미리보기:** 편집 내용 즉시 반영
- **이미지 다운로드:** PNG 및 JPEG 파일로 내보내기
- **템플릿 관리:** SAVE, LOAD, UPDATE, DELETE
- **JSON 백업:** 템플릿을 JSON 파일로 내보내고 다시 가져오기
- **로컬 저장:** 브라우저에 저장된 템플릿 유지
- **반응형 레이아웃:** 데스크톱 및 모바일 화면 대응

## 사용 기술

- HTML5
- CSS3
- JavaScript
- Git / GitHub
- GitHub Pages

## 사용 방법

1. 배포 사이트에 접속합니다.
2. 이미지 파일을 업로드합니다.
3. 텍스트를 입력하고 크기, 색상, 위치를 조절합니다.
4. 원하는 카드 비율을 선택합니다.
5. 미리보기를 확인한 후 PNG 또는 JPEG로 다운로드합니다.
6. 필요하면 템플릿을 저장하거나 JSON 파일로 백업합니다.

## 기능 테스트

다음 항목을 직접 테스트했습니다.

- 긴 문장 자동 줄바꿈 및 카드 영역 내 표시
- 텍스트 X/Y 위치 조절
- 1:1, 4:5, 9:16 비율별 미리보기
- 이미지 업로드 및 표시
- PNG/JPEG 다운로드
- 템플릿 저장, 불러오기, 수정, 삭제
- JSON 내보내기 및 가져오기
- JSON 복원 후 이미지, 문구, 비율 유지
- 새로고침 후 저장된 템플릿 불러오기
- 잘못된 JSON 파일 입력 시 오류 처리
- 시크릿 모드 접속 및 기능 테스트
- 390px 모바일 화면 레이아웃 확인

## 프로젝트 특징

사용자가 브라우저에서 직접 카드 이미지를 제작하고 관리할 수 있도록 구현했습니다.

템플릿을 저장하고 다시 불러오는 기능을 제공하며, JSON 파일을 통한 백업 및 복원도 지원합니다. 잘못된 JSON 파일을 가져오더라도 기존 템플릿이 유지되도록 오류 처리 기능을 적용했습니다.
